# java-calculator-precourse

## 구현할 기능 목록

1. 문자열 숫자 분리 후 합계 계산
    - 입력 문자열을 구분자(",",":")로 나누어 각 숫자를 합산
2. 공백 및 빈 문자열 처리
    - 각 토큰에 공백 제거(trim)및 빈 문자열 무시
3. 사용자 입력 및 커스텀 구분자 지원
    - 사용자 입력 처리, 필요 시 커스텀 구분자 적용
4. 결과 출력
    - 계산된 합계를 콘솔에 출력
5. 예외 처리 및 프로그램 종료
   - 잘못된 입력(숫자가 아닌 값) 및 음수 입력 시 IllegalArgumentException을 발생시키고 프로그램 종료
